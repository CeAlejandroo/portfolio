# Cómo implementar modales en la sección de Portafolio

¡Hola! Como estás aprendiendo programación, te explico paso a paso cómo logramos que al hacer clic en las tarjetas del portafolio se abra una ventana modal. Esto es un concepto común en desarrollo web usando React y Next.js.

## ¿Qué es un modal?

Un modal es una ventana emergente que aparece sobre el contenido principal de la página. Se usa para mostrar información adicional sin navegar a otra página.

## Componentes utilizados

Usamos componentes de la biblioteca shadcn/ui, que está basada en Radix UI:

- `Dialog`: El contenedor principal del modal
- `DialogTrigger`: El elemento que activa el modal (nuestras tarjetas)
- `DialogContent`: El contenido que se muestra dentro del modal
- `DialogHeader`, `DialogTitle`, `DialogDescription`: Para estructurar el contenido del modal

## Paso 1: Importar los componentes

```typescript
import {
  Dialog,
  DialogContent,
  DialogDescription,
  DialogHeader,
  DialogTitle,
  DialogTrigger,
} from "@/components/ui/dialog"
```

Esto nos permite usar los componentes del modal en nuestro código.

## Paso 2: Estado para controlar el modal

```typescript
const [openModal, setOpenModal] = useState<string | null>(null)
```

- `useState` es un hook de React para manejar estado
- `openModal` guarda cuál modal está abierto (o null si ninguno)
- `setOpenModal` es la función para cambiar este estado

## Paso 3: Estructura del modal

Cada tarjeta del portafolio está envuelta en un `Dialog`:

```jsx
<Dialog>
  <DialogTrigger asChild>
    <div className="portfolio-card" onClick={() => setOpenModal("ecommerce")}>
      {/* Contenido de la tarjeta */}
    </div>
  </DialogTrigger>
  <DialogContent>
    <DialogHeader>
      <DialogTitle>Título del proyecto</DialogTitle>
      <DialogDescription>Descripción breve</DialogDescription>
    </DialogHeader>
    <div>
      {/* Contenido detallado del modal */}
    </div>
  </DialogContent>
</Dialog>
```

## Paso 4: Cómo funciona el clic

- `onClick={() => setOpenModal("ecommerce")}`: Cuando se hace clic, cambia el estado a "ecommerce"
- El `DialogTrigger` detecta el clic y abre el modal automáticamente
- El modal se cierra cuando se hace clic fuera o en el botón de cerrar

## Conceptos de programación aprendidos

1. **Componentes**: Bloques reutilizables de UI
2. **Estado (State)**: Datos que cambian con el tiempo
3. **Eventos**: Acciones del usuario (como clics)
4. **Props**: Propiedades que se pasan a componentes
5. **JSX**: Sintaxis para escribir HTML en JavaScript

## Cómo centrar la imagen en el modal

Para hacer que la imagen en el modal se vea centrada y bien presentada, como los emojis en las tarjetas del portafolio, seguimos estos pasos:

### Paso 1: Agregar la imagen al contenido del modal

En el `DialogContent` del proyecto "Almuercito escolar", agregamos un contenedor para la imagen:

```jsx
<div className="modal-content">
  <div className="modal-image">
    <img src="/images/almuercito.png" alt="Almuercito escolar" />
  </div>
  {/* Resto del contenido */}
</div>
```

### Paso 2: Crear estilos CSS para centrar la imagen

Agregamos estilos CSS en el `<style jsx global>` de `app/page.tsx`:

```css
.modal-content {
  display: flex;
  flex-direction: column;
  gap: 20px;
}

.modal-image {
  display: flex;
  justify-content: center;
  align-items: center;
  height: 200px;
  background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
  border-radius: 15px;
  overflow: hidden;
}

.modal-image img {
  max-width: 100%;
  max-height: 100%;
  object-fit: contain;
}
```

### Explicación de los estilos

- `.modal-content`: Organiza el contenido del modal en columna con espacio entre elementos
- `.modal-image`: 
  - `display: flex` con `justify-content: center` y `align-items: center`: Centra la imagen horizontal y verticalmente
  - `height: 200px`: Define una altura fija para consistencia
  - `background`: Aplica el mismo gradiente que las tarjetas para mantener el estilo
  - `border-radius` y `overflow: hidden`: Redondea las esquinas y oculta cualquier desbordamiento
- `.modal-image img`:
  - `max-width` y `max-height: 100%`: La imagen no excede el contenedor
  - `object-fit: contain`: Mantiene las proporciones de la imagen sin recortarla

Esto hace que la imagen se vea centrada y proporcional, similar a cómo los emojis están centrados en las tarjetas del portafolio.
